# Engineering Roadmap

A structured journey toward becoming a systems and AI engineer through
fundamentals, practical implementation, and engineering projects.

## Core Philosophy

- Understand concepts before using abstractions.
- Implement systems from scratch wherever practical.
- Focus on C++ and low-level engineering.
- Build projects that demonstrate real engineering skills.
- Integrate individual learnings into a unified Tensor Library.

## Learning Roadmap

1. Operating Systems
2. Computer Networks
3. Computer Architecture
4. Mathematics for Machine Learning
5. CUDA Programming
6. Machine Learning
7. Deep Learning
8. Computer Vision
9. LLM Engineering
10. Distributed Systems
11. System Design

## Major Engineering Initiative

### Tensor Library

An independently implemented C++ library designed to grow into a unified
computing and AI framework.

Planned modules:

- Tensor Core and Mathematical Operations
- CPU Execution Runtime
- CUDA Backend
- Automatic Differentiation
- Neural Network Engine
- Computer Vision
- Transformer and LLM Engine
- Communication and Distributed Computing
